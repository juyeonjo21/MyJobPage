# MyJobPage — 인증 프로젝트 접수·진행현황 대시보드

스탠다드뱅크 인증 프로젝트의 접수·진행현황을 보는 Streamlit 대시보드입니다.

> 교육용 가상 데이터 기준 — 실제 업무 시스템 아님. 메일 발송·외부 시스템 연동 없음.

## 기능
- 요약 카드(전체·진행상태별 건수), 기준일 선택(기본 2026-10-23)
- 사이드바 다중 선택 필터: 시험분야 / 적용규격 / 담당엔지니어 / 진행상태 / 시료상태
- 잔여일수(완료예정일 − 기준일)와 일정 상태(완료 / 지연 후보 / 오늘 마감 / 진행 예정 / 일정 확인 필요), 지연 후보 행 강조
- 시험분야별 건수 막대그래프, 진행상태 비율 도넛 차트
- 시험분야 관리(등록 / 이름 변경 / 재분류 후 삭제) — 변경 내용은 세션에만 보관
- 전체 목록·현재 필터 결과 Excel(.xlsx) 다운로드 (프로젝트목록 / 상태별집계 / 담당자별집계 / 분석조건 시트)

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

데이터: `data/SB_project_demo.csv` (또는 `data/SB_projects_demo.csv`). 파일이 없으면 화면에서 CSV를 업로드할 수 있습니다.
